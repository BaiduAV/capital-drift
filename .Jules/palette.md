## 2026-09-08 - Trade Page Keyboard Accessibility\n**Learning:** Custom interactive elements representing list items (e.g., clickable rows acting as buttons) require manual implementation of `role="button"`, `tabIndex`, and `onKeyDown` event listeners for Enter/Space, in addition to visual `focus-visible` classes, to be properly accessible to keyboard users.\n**Action:** When implementing clickable `div` or `span` elements acting as buttons or interactive rows, always ensure they are fully operable via keyboard by adding standard accessibility attributes and key handlers.
